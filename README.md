# Freaky TD

A Tower defense, based on the [Freaky Engine](https://github.com/hugoschool/r-type).

## Context

This project is made to be a test project for the [Freaky Engine, present in the R-Type project](https://github.com/hugoschool/r-type).

## Contributing

Same contributing rules as the [R-Type project](https://hugoschool.github.io/r-type/contributing.html).

Issues for this project also live on the main R-Type repository.
